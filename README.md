## ⚡ Key Highlights & Features

- **Cinematic Opening Intro**: Atmospheric near-black void, expanding electric blue laser line, bold brand reveal, and high-speed light sweep.
- **Advanced Parallax Hero**: Multi-plane depth shift tracking cursor coordinates on desktop, studio vehicle view switcher (Porsche Studio Bay, Snow Foam Wash, 10H Ceramic, Active Bay).
- **Interactive Service Panels**: 6 core studio disciplines with hover expansion, electric blue accents, and detailed specifications.
- **PPF High-Impact Showcase**: Real technician application photography, self-healing TPU technology breakdown, and package tiers.
- **10H Nano-Ceramic Section**: High-impact 115° hydrophobic water beading visual with performance metric cards.
- **Interactive Before / After Slider**: Zero-distortion hardware-accelerated CSS `clip-path` comparison slider with touch drag and accessible range controls.
- **4-Step Protocol Timeline**: 01 INSPECT → 02 PREPARE → 03 DETAIL → 04 DELIVER with responsive horizontal/vertical timeline.
- **Mansarovar Flagship Studio Facility**: Showcasing 6500K CRI hex inspection canopies, dust-free bays, and consultation lounge.
- **Editorial Automotive Gallery**: Filterable category masonry layout with full-resolution lightbox modal.
- **Official WhatsApp & Call Booking System (`+91 99504 02250`)**:
  - Modal form with real-time in-modal WhatsApp preview box.
  - Automatically formats an executive WhatsApp markdown message with clean bullet points.
  - Desktop floating WhatsApp badge + mobile sticky bottom action bar with safe-area padding.
- **Complete Local SEO**: Full schema.org `AutoRepair` structured data, Open Graph cards, geo-coordinates, and meta tags for Mansarovar, Jaipur.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
# Navigate to project folder
cd aurum-shine

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
```
